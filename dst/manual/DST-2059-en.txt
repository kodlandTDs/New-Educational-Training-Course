HOW TO BUILD THIS FORM BY HAND
--------------------------------------------------------------------------
 1. Go to forms.google.com and start a Blank form.
 2. Paste the TITLE below into the form title, and the DESCRIPTION under it.
 3. Open Settings (gear icon):
    - turn ON "Make this a quiz"
    - Release grade: "Immediately after each submission"
    - Respondent can see: tick "Missed questions", "Correct answers", "Point values"
    - under Responses, turn ON "Collect email addresses"
    - turn OFF "Allow response editing" and the link to submit another response
 4. Add the 2 identification questions from SECTION 1 (both Short answer, Required).
    On the e-mail question use the three-dot menu > Response validation > Text > Email.
 5. Add a section break, title it with the SECTION 2 heading.
 6. For each of the 12 questions:
    - add a Multiple choice question, Required
    - paste the QUESTION line into the question title
    - click Option 1, then paste all four OPTION lines at once — Forms splits them
    - click "Answer key", select the correct option, set 1 point
    - click "Add answer feedback" and paste FEEDBACK into both boxes, correct and incorrect
 7. Add a section break, title it with the SECTION 3 heading.
 8. Add the 3 rating questions as "Linear scale", 1 to 5, with the labels given, Required.
 9. Add the last question as "Paragraph", Required, with the help text given.
10. Send > copy the link, and paste it into finalDst.url for this course.

    Quiz settings: 1 point per question, 12 points total, pass mark 10/12
